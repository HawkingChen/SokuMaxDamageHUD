# SokuMaxDamageHUD · 什么最痛

[简体中文](README.md) · [English](README.en.md) · **日本語**

『東方非想天則』**v1.10a** 用のダメージ表示 MOD です。ゲームウィンドウの下に、技の推定ダメージ、各種補正、対戦中の最大ダメージ記録を表示します。中国語・日本語・英語に対応しています。

**戦闘データの読み取り専用 MOD です。** 実行中の戦闘状態を読み取り、推定と表示にのみ使用します。実際のダメージ、キャラクターの能力値、戦闘状態を変更せず、通信パケットや乱数（RNG）にも介入しません。ゲームへの操作入力も行いません。画像の抽出では元のゲームアーカイブを変更せず、生成画像と表示設定は MOD 自身のフォルダーに保存します。

## 導入方法

MOD を読み込める環境（SokuLauncher / SokuModLoader / SWRSToys）と、非想天則 v1.10a が必要です。

1. ゲームを終了し、[Releases](https://github.com/HawkingChen/SokuMaxDamageHUD/releases/latest) から `SokuMaxDamageHUD-vバージョン番号-win32.zip` をダウンロードします。Source code ではありません。
2. ZIP 内の **`SokuMaxDamageHUD` フォルダー**を、ゲームの **`modules`** フォルダーに展開します。
3. **SokuLauncher の MOD 一覧で SokuMaxDamageHUD を有効化**して、ゲームを起動します。

DLL の配置先は `ゲームフォルダー/modules/SokuMaxDamageHUD/SokuMaxDamageHUD.dll` です。

<details>
<summary>SWRSToys を直接使用する場合</summary>

使用中の `SWRSToys.ini` の `[Module]` セクションに追加します。

```ini
SokuMaxDamageHUD=modules/SokuMaxDamageHUD/SokuMaxDamageHUD.dll
```

同じ DLL を別名の項目で重複して読み込まないでください。

</details>

**カード画像の別途ダウンロードは不要です。** 初回起動時に、お使いのゲームの `th123a.dat` / `th123b.dat` / `th123c.dat` からカードと天候の画像を読み出し、MOD の `icons` フォルダーに保存します。元のアーカイブや既存画像は変更しません。ネット接続、Python、追加スクリプトも不要です。画像が出ない場合は、ゲームのデータファイル、MOD フォルダーへの書き込み権限、`IconExtraction.log` を確認してください。抽出に失敗しても文字の代替表示は利用できます。

更新時は旧フォルダーをバックアップし、ゲームを終了してから新版のファイルを上書きしてください。削除する場合は、ランチャーで無効化してから `SokuMaxDamageHUD` フォルダーを削除します。

## 使い方

- **ダメージ補正**：大きなパーセント表示は攻撃・防御の共通補正です。根性補正は灰色、必殺技とスペルカードの補正は別枠で表示します。重なったカードで効果と枚数を確認できます。
- **最大ダメージ必殺技**：使用可能な既知の必殺技のうち、推定ダメージが最も高い技です。B/C 版が同ダメージの場合は `623B/C` のようにまとめます。
- **最大ダメージ記録**：その対戦で記録した単一技の最大ダメージです。通常技やスペルカードも対象です。
- **手札**：手札の順番にスペルカードの推定ダメージを表示します。
- **CN / JP / EN** ボタンで言語を順番に切り替えます。2 個の方向ボタンで別の配置へ切り替え、太い上向きボタンで折りたたみます。ゲーム画面右下の半透明 **＋** で展開します。設定は自動保存されます。

**ウィンドウ配置（0.5.1 以降）**：下・左・右に配置できます。縦型はゲームウィンドウと同じ高さ、横型は下端に隙間なく配置します。起動後の初回展開時のみ、クライアント領域を 4:3 に保ってゲームのサイズを自動調整できます。以後の非表示・折りたたみ・配置切替・対戦終了ではゲームのサイズを変更せず、ユーザーによるウィンドウ操作に追従します。

| 操作 | 初期ショートカット |
| --- | --- |
| HUD の表示 / 非表示 | Ctrl + Shift + H |
| 横型 / 縦型の切替 | Ctrl + Shift + O |
| 下 / 左 / 右への配置切替 | Ctrl + Shift + P |

ショートカットはゲームが前面にある対戦中に動作します。ボタン以外をドラッグすると半透明の静止プレビューが移動し、離すと最も近い下・左・右に配置されます。自由配置はありません。ドラッグ中もダメージ記録を継続します。対戦終了時と他のアプリへの切替時は非表示になります。

通常のウィンドウと **WindowResizer のボーダーレス全画面**に対応し、排他的全画面には対応しません。選択した側にスペースが足りなければ HUD 自身を縮小し、外側に配置できない場合はゲームの端に重ねます。ゲームを再度縮小することはありません。`SokuMaxDamageHUD.ini` の `[HUD] AutoFit=0` で初回調整を禁止、`SideWidth` で縦型の幅を変更できます。キーは `[Hotkeys]` で設定します。

## 制限事項

- `≈` は推定値を表します。完全なダメージシミュレーターではありません。技のレベル、ヒット数、位置、一部の特殊状態によって実際の結果は変わります。初段強化を多段技全体の推定値に掛けることはありません。
- 記録では弾の発生元を追跡し、同じ発動中の多段ヒットを合算します。複数の発生元が同時に命中した場合などは、技名を特定できないことがあります。未収録の技データもあります。
- ネット対戦のホスト・クライアント、観戦、リプレイ、他の MOD との組み合わせは、すべての実機確認を終えていません。ゲームのダメージや通信パケットは変更しません。
- 画像の自動抽出には、この機能を含む新しいビルドが必要です。過去のリリース ZIP には自動で追加されません。
