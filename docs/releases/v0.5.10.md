# SokuMaxDamageHUD v0.5.10 · 什么最痛

本次主要更新实际伤害归属与记录。**仍未完成所有角色、技能和特殊情况的逐项实机验证；伤害预测继续作为参考估算。**

## 更新内容

- 实际记录改为采集游戏逐击结算、动作和对象创建事件，不再用连段总伤害反推招式名称。
- 补齐二十个角色各自的弹幕创建工厂，追踪同一次施放产生的多个弹幕，改善芳波等多段技能漏记的问题。
- 保留延迟爆炸的原始施放来源，分开累计对手受伤与自伤，避免把两者相加或认成其他符卡。
- 修复跨回合复用施放编号时误清除旧记录的问题；实际记录不再使用固定的静态伤害倍率上限。
- 无法归属的命中和伤害采集不可用时，HUD 明确提示，避免只显示旧记录却看不出信息缺失。
- 中、英、日说明明确标注：MOD 会使用函数与虚表 Hook 读取事件，但不改写游戏伤害、属性、网络封包或随机数，不发送战斗操作。
- 两种诊断日志均默认关闭。关闭日志不影响 HUD 统计；修改日志开关后需重启游戏。

## 验证范围与限制

Windows x86 构建、核心回归与 Hook 夹具通过；包括全角色工厂分派、延迟创建链、自伤分账、跨回合和芳波五击 1797 的回归场景。此前魔理沙普通弹幕与延迟爆炸已有实机记录，22 改获用户确认。

**这些结果不等于全角色、全技能已经验证。** 0.5.10 的全角色工厂路径、完整连段、部分特殊扣血机制、联网回滚及其他 MOD 组合仍需更多实机反馈。若出现异常，请附角色、招式、模式、版本和复现步骤。

## 安装／更新（三步）

1. 退出游戏，下载下面的 **`SokuMaxDamageHUD-v0.5.10-win32.zip`**，不要下载 Source code。
2. 解压，将其中的 **`SokuMaxDamageHUD` 文件夹**放入游戏的 **`modules`** 目录。升级前备份旧版；保留自己的图标和界面设置，避免同时加载两份 MOD。
3. 在 **SokuLauncher / SokuModLoader** 中启用后启动游戏。使用 SWRSToys 的玩家，确认已加载 `modules/SokuMaxDamageHUD/SokuMaxDamageHUD.dll`。

适用于《东方非想天则》**v1.10a**，支持简体中文、日本語、English。卡图从玩家本机游戏资源提取；安装包不包含游戏图片、截图或诊断日志。
