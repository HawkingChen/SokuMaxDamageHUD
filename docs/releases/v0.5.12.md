# SokuMaxDamageHUD v0.5.12 · 什么最痛

本次重点修正实际伤害重复累计和持续伤害漏记。

## 更新内容

- 接入 Giuroll 0.6.18 的官方回滚回调，让 HUD 的伤害记录、招式来源和待处理事件随游戏状态一起恢复，修正预测重演后伤害越记越高的问题。无需修改 Giuroll 或启动器配置。
- 补齐铃仙毒气、幽幽子持续扣血的采集路径，改善伤害超过旧记录却不更新的问题。
- 修正妖梦常驻半灵的指令归属；换招后，之前发出的弹幕继续保留原来的来源。
- 保留诹访子部分自动派生动作的原始出招归属，避免同一招中途变成另一个记录。
- 避免把自己受到的攻击、对方自伤或反弹后的伤害误计为自己的输出；经原生事件确认的自伤仍单独统计。
- 新增全角色事件回归，以及重复预测、真实多段命中和练习模式回血等回归检查。不以静态伤害上限掩盖异常。

## 验证范围

Windows x86 的七项自动测试通过，两组全角色回归包含 **16,385 次已观察到的伤害事件**。

**本轮回滚修正尚未完成重启后的实机验证，也未完成全角色、全技能及所有特殊状态的逐项实测。** 自动场景中仍有招式未能重现伤害，不能视作已经验证；伤害预测继续作为参考估算。其他版本的回滚模组及复杂 MOD 组合也仍需反馈。

## 安装／更新

1. 退出游戏，下载 **`SokuMaxDamageHUD-v0.5.12-win32.zip`**，不要下载 Source code。
2. 解压，将其中的 **`SokuMaxDamageHUD` 文件夹**放入游戏的 **`modules`** 目录。升级前备份旧版，保留自己的图标和 INI 设置，避免同时加载两份 MOD。
3. 在 **SokuLauncher / SokuModLoader** 中启用后重新启动游戏。仅替换文件不会更新正在运行的游戏进程。

适用于《东方非想天则》**v1.10a**，支持简体中文、日本語、English。卡图从玩家本机游戏资源提取；安装包不包含游戏图片、截图或诊断日志，两种诊断日志默认关闭。
