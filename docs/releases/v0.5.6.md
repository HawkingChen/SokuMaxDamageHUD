# SokuMaxDamageHUD v0.5.6｜什么最痛

《东方非想天则》的伤害分析 HUD 更新了！想知道自己的招式能打多痛、这局哪一招打出了最高伤害？打开游戏就能看到。

## 这次更新

- **三种显示位置自由切换**：HUD 可以放在游戏的**下方、左侧或右侧**。点击面板上的方向按钮，或用**鼠标拖动**面板到游戏窗口边缘，就能切换；靠近边缘时会有半透明吸附预览。
- **更适合全屏玩游戏**：支持普通窗口和 WindowResizer 的**无边框全屏**，空间不足时会自动调整显示位置和窗口大小，尽量不遮挡游戏画面。*不支持独占全屏。*
- **修复红美铃「彩光莲华掌」的招式识别**：改善符卡发动和追击演出之间的伤害归属，让同一次符卡的伤害有机会正确累计为一个纪录。
- **英文 UI 更清爽**：过长的倍率标签缩写为 `SKILL` 和 `SC`，避免遮住后面的倍率。
- **继续完善伤害统计**：改进可用技能与等级筛选、部分黄沙／虎劲首段增伤，以及持续弹幕的伤害纪录。具体数字仍为参考估算，一些复杂多段招式需要实机验证。

支持 **简体中文／日本語／English**。MOD 仅读取游戏数据进行显示，不会修改实际伤害或战斗操作。

## 安装／更新（简单三步）

1. 退出游戏，下载下方的 **`SokuMaxDamageHUD-v0.5.6-win32.zip`**（不要下载 GitHub 自动提供的 Source code）。
2. 解压后，将 ZIP 内的 **`SokuMaxDamageHUD` 文件夹**放入游戏的 **`modules`** 文件夹。更新旧版建议先备份，再覆盖相应文件，并保留自己的 `icons` 和设置。
3. 在 **SokuLauncher／SokuModLoader** 中启用这个 MOD，重新启动游戏即可。直接使用 SWRSToys 的玩家，请确认 `SWRSToys.ini` 中已正确加载 `modules/SokuMaxDamageHUD/SokuMaxDamageHUD.dll`。

**适用版本**：东方非想天则 v1.10a；Windows x86 MOD，可在 Steam Deck 的 Proton 环境下使用，但部分全屏、持续技纪录行为仍需实机确认。

**无需额外下载卡图**：MOD 会尝试从你本机游戏资源中提取卡图和天气图标，不会联网下载资源。安装包不包含原作图片。
