# SokuMaxDamageHUD v0.5.7｜什么最痛

《东方非想天则》的伤害分析 HUD 更新了！这次主要修复**延迟弹幕和近身攻击同时命中时，最高伤害纪录把两招误算成一招**的问题。

## 本次更新

- **修复萃香 5C＋J6A 的最高伤害误判**：此前 5C 延迟爆炸与 J6A 重叠命中，可能把整段连击的 3057 伤害都显示成「J6A」。现在优先读取这一帧实际扣除的 HP；**同一帧两个来源无法准确拆分时，不会再把合计伤害当成某一招的最高纪录**。5C、J6A 单独使用时仍能各自记录。
- **最痛必杀技会考虑特殊首击强化**：黄沙天气下，有「与CH」资格且资料已确认的招式，首段 CH 加成会计入最痛候选；红美铃的**虎劲、猛虎内劲**只强化符合条件的**体术打击第一 Hit**，纯弹幕不享受加成。不会把整套多段招式简单乘上同一个首击倍率。
- **萃香巨大化也有对应的最痛计算**：发动四卡「ミッシングパープルパワー」变身后，不能使用普通必杀技时，HUD 暂时切换为显示巨大化状态下**实际可用的普通招式**；变身结束恢复平常必杀技候选。
- **持续技能与特殊符卡纪录**：改进持续弹幕、受身后再次命中和红美铃「彩光莲华掌」追加演出的招式归属。同一次施放可以累积自己的伤害，重新施放仍分开统计。
- **HUD 支持三种布局**：下方横向、左侧竖向、右侧竖向；可以点击按钮切换，也可以用鼠标拖拽到游戏窗口边缘吸附。支持窗口模式与 WindowResizer **无边框全屏**（不支持独占全屏）。
- **英文界面更紧凑**：必杀技和符卡倍率标签分别显示为 `SKILL`、`SC`，不再遮挡倍率数字。

以上特殊伤害机制使用已有资料进行保守估算；部分技能等级、多段命中和黄沙 CH 资格仍缺少完整实机数据，因此「≈」伤害不代表所有条件下的精确极限值。

## 安装／更新（三步）

1. **退出游戏**，下载下面的 **`SokuMaxDamageHUD-v0.5.7-win32.zip`**（不要下载 GitHub 自动生成的 Source code）。
2. 解压 ZIP，将里面的 **`SokuMaxDamageHUD` 文件夹**放进游戏目录的 **`modules`** 文件夹。升级前建议备份旧版并保留自己的 `icons` 和设置。
3. 在 **SokuLauncher / SokuModLoader** 里启用 MOD 后启动游戏。使用 **SWRSToys** 的玩家，检查 `SWRSToys.ini` 已加载 `modules/SokuMaxDamageHUD/SokuMaxDamageHUD.dll`，避免重复加载。

适用于《东方非想天则》v1.10a，提供简体中文、日文和英文 HUD。安装包不包含原作卡牌图片；MOD 会从玩家自己的游戏资源中提取。

**实机反馈建议**：用萃香单独 5C（参考约 2280）、单独 J6A，再在 5C 延迟命中同时出 J6A；观察是否不再出现「J6A 3057」。若两招真正同时命中且无法可靠拆分，这一帧不会作为某一单招的新纪录。也欢迎测试连续施放相同的持续技能。
