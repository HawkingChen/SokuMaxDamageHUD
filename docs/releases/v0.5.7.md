# SokuMaxDamageHUD v0.5.7｜什么最痛

《东方非想天则》的伤害分析 HUD，可查看实时伤害倍率、最痛必杀技、实际最高伤害纪录与手牌伤害。

### 本次更新

- 优化持续性弹幕与连续攻击的伤害纪录归属，包括**萃香 5C、红美铃彩光莲华掌**等情况。
- **黄沙天气、虎劲、猛虎内劲**等符合条件的首击强化，会参与「最痛必杀技」的候选伤害估算；弹幕与体术按实际适用条件区分。
- **萃香四卡巨大化**期间，「最痛必杀技」会临时切换为巨大化状态可使用的普通招式。
- HUD 可在**下方、左侧、右侧**显示，支持按钮与鼠标拖拽切换，以及 WindowResizer 无边框全屏。
- 英文伤害倍率标签简化为 **SKILL / SC**。

**当前已知问题：**萃香延迟 5C 与 J6A 重叠命中时，实际最高伤害的招式归属仍可能错误。正在进一步修复，当前版本暂不视为此问题已解决。

### 安装／更新

1. 退出游戏，下载下方的 **`SokuMaxDamageHUD-v0.5.7-win32.zip`**（不要选 Source code）。
2. 将压缩包内的 **`SokuMaxDamageHUD` 文件夹**解压到游戏的 **`modules`** 目录，更新前建议备份并保留已有 `icons` 和个人设置。
3. 在 **SokuLauncher / SokuModLoader** 启用 MOD 后启动游戏；直接使用 SWRSToys 时确认 `SWRSToys.ini` 已加载相应 DLL。

适用于《东方非想天则》v1.10a。HUD 支持中文、日文、英文。安装包不包含原作卡牌图片。
